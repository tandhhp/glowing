# Frontend

Giao diện React + Tailwind cho web app luyện nói tiếng Anh:

- Hành trình chủ đề theo chặng
- Core AI Loop (transcript -> chấm điểm -> phản hồi)
- Streak/XP/Quests/Badges/Leaderboard
- Hiển thị Prompt Engineering mẫu dùng để gọi OpenAI/Claude

## Chạy local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
